# Project instructions

## Communication and changes
- Reply in English and explain things simply.
- Briefly describe your approach before editing.
- Change only what the current task requires.
- Ask before deleting files.
- If information is missing, ask; do not invent results.

## Verification
- Find check commands in the project documentation; do not invent them.
- Run appropriate checks after making changes.
- Report what changed, what you checked, and what remains unverified.
