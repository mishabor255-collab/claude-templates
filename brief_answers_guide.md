# BRIEF: make Claude's answers shorter

These are account-wide instructions in the app; no instruction file is required.
They apply across conversations, but you should still review the result.

1. Open Claude on the web or desktop.
2. Click your initials at the bottom left → Settings.
3. Select Your Claude → Instructions.
4. Older layouts use Account → Instructions for Claude.
5. Add this rule while preserving useful existing instructions:
> Keep answers brief and use plain language. Skip introductions and repetition. Lead with the result. Include explanations when needed to make the answer understandable.
6. Save if your interface displays a save button.
7. Start a new chat and ask:
> Write a notice: the elevator is broken, so please use the stairs. Do not invent a repair date. Two sentences maximum.
8. Check the notice is short and contains no invented deadlines.
9. Ask explicitly for more detail when tackling a complex task.

Do not put temporary details, such as a repair date, in account-wide instructions.
If answers become too short, refine the rule in the same field.
