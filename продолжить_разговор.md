# ДАЛЬШЕ — продолжить разговор в Claude Code

Для терминальной версии Claude Code. Нужен ранее сохранённый разговор.
1. Открой терминал в той же папке проекта, где общался раньше.
2. Выполни команду:
```sh
claude --continue
```
Короткая запись той же команды: `claude -c`.
3. Проверь, что открылся нужный разговор, и продолжай задачу.

## Если нужен другой разговор
В терминале выполни `claude --resume` и выбери разговор из списка.
Если Claude Code уже открыт, введи `/resume` в его строке запроса.
Не путай `/resume` с командой обычного терминала.

## Если разговор не найден
Проверь папку проекта и наличие сохранённой истории на этом компьютере.
Без подходящей истории `--continue` сообщает, что разговор не найден.
Это продолжение переписки, а не восстановление удалённых файлов проекта.
Перед работой проверь текущее состояние файлов: оно могло измениться.
