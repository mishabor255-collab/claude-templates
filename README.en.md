## How to use the CLAUDE.md template
1. Download `CLAUDE_template.en.md` and put it in the root of your project.
2. Rename it to `CLAUDE.md`.
3. Replace the text in [square brackets] with your own. Delete anything you don't need.
4. Run `claude` in the project folder — it reads the file automatically.

The template is deliberately not named `CLAUDE.md`, so Claude Code running in this folder doesn't treat it as real instructions.
