# Шпаргалка: три режима Claude Code для начала

В терминале Claude Code режимы переключаются клавишами **Shift+Tab** — каждое нажатие включает следующий:
**Manual → accept edits → plan**. Текущий режим написан внизу окна.

| Режим | Надпись внизу | Что делает Claude | Когда включать |
|---|---|---|---|
| **Ручной (Manual)** | `manual mode on` | Спрашивает разрешения перед большинством правок файлов и команд; заранее разрешённые действия выполняет без вопроса | По умолчанию, когда учишься или проект важный |
| **Авто-правки** | `accept edits on` | Сам вносит правки и выполняет некоторые простые файловые команды; остальное — по правилам разрешений | Когда доверяешь задаче и не хочешь подтверждать каждую правку |
| **Планирование** | `plan mode on` | Изучает проект и составляет план, **не редактируя код**; к правкам переходит только после твоего одобрения | Большие задачи, незнакомые проекты, «сделай красиво» |

## Как работать в режиме планирования
1. Нажимай **Shift+Tab**, пока внизу не появится `plan mode on`.
2. Опиши задачу обычными словами.
3. Прочитай план. Не нравится — скажи, что изменить («только кнопку, остальное не трогай»).
4. Всё устраивает — одобри план и выбери, как подтверждать правки. Claude приступит к работе.

## Полезные мелочи
- **Esc** — прервать текущее действие. Уже сделанные изменения при этом сохраняются.
- Режим переключай **Shift+Tab** вне окон подтверждения (в окне одобрения плана эта клавиша работает иначе).
- Постоянные инструкции для проекта запиши в файл **CLAUDE.md** в папке проекта (шаблон — рядом).

Есть и другие режимы — подробнее в официальной документации: <https://code.claude.com/docs/en/permission-modes>
Не является официальным материалом Anthropic.
