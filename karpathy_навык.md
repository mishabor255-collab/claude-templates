# ПРОЩЕ — навык Karpathy guidelines в приложении Claude

Навык из репозитория andrej-karpathy-skills — набор правил для задач с кодом:
уточняй задачу, не усложняй, меняй только нужное, проверяй результат.
Это правила для модели, а не гарантия: изменения всё равно просматривай.

## Шаги (приложение или сайт Claude)
1. Открой https://github.com/multica-ai/andrej-karpathy-skills → **Code → Download ZIP**, распакуй.
2. Найди папку `skills/karpathy-guidelines` (внутри файл `SKILL.md`).
3. Запакуй **эту папку** в ZIP (Mac: правый клик → «Сжать»; Windows: «Отправить → Сжатая папка»).
4. В Claude: **Настройки → Capabilities** — включи выполнение кода (Code execution), если выключено.
5. Там же в разделе **Skills** нажми **Upload skill** и выбери свой ZIP.
6. Включи переключатель у навыка. Попроси: «Сделай одну кнопку „Заказать“, без лишнего».

## Если раздела Skills нет
- Навыки доступны не на всех тарифах — проверь в справке Claude.
- Запасной вариант: создай Проект и вставь текст из `CLAUDE.md` этого репозитория в инструкции проекта.
