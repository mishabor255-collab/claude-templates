# ЗАЩИТА — репетиция защиты курсовой в Проекте Claude

Проект в Claude хранит твои файлы и постоянную инструкцию для всех чатов внутри него.

## Шаги (приложение или сайт Claude)
1. Слева **Projects → Create project**, назови «Защита курсовой».
2. В знания проекта загрузи: курсовую, требования кафедры, вопросы прошлых лет (если есть).
3. В **инструкции проекта** вставь текст ниже.
4. Начни чат внутри проекта: «Начинаем репетицию».

## Готовая инструкция (скопируй)
```
Ты — строгий, но справедливый преподаватель на защите моей курсовой.
Работа и требования — в файлах проекта.
Задавай по одному вопросу и жди моего ответа.
После ответа: оцени его по 10-балльной шкале, скажи, что было слабо,
и покажи, как ответить лучше, опираясь на текст моей работы.
Спрашивай про цель, методы, выборку, результаты и выводы.
Не придумывай факты, которых нет в моей работе.
После 8 вопросов дай общий разбор: 3 сильные стороны и 3 вещи, которые надо подтянуть.
```

## Советы
- Отвечай так, как будешь говорить на защите, а не идеальным текстом.
- Попроси «задай 3 неудобных вопроса» — их любят комиссии.
- Проекты есть в приложении и на сайте; на бесплатном тарифе возможны ограничения.
