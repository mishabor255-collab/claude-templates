# ФАЙЛ — укажи нужный файл через @

Для строки запроса Claude Code, не для командной оболочки.
1. Открой Claude Code в папке проекта.
2. Найди путь к нужному существующему файлу.
3. Добавь `@` прямо перед путём, без пробела:
```text
Объясни функцию входа в @src/login.js. Пока ничего не меняй.
```
`src/login.js` — пример: замени его реальным путём своего файла.
Относительный путь считается от рабочей папки; допустим и абсолютный.

## Как это помогает
Упоминание задаёт конкретный файл и добавляет его содержимое в контекст, если оно укладывается в лимиты.
Набери `@`, чтобы увидеть подсказки путей; проверь выбранный путь перед отправкой.
Для первого опыта выбери небольшой текстовый файл.
Для папки `@src/` добавляется список файлов, а не весь их код.

## Проверь результат
Сверь имя файла и объяснение с реальным кодом.
Упоминание файла не запрещает Claude обращаться к другим файлам.
Точный путь помогает задать контекст, но не гарантирует правильный ответ.
