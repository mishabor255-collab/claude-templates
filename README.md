## Как пользоваться шаблоном CLAUDE.md
1. Скачай `CLAUDE_шаблон.md` и положи в корень своего проекта.
2. Переименуй в `CLAUDE.md`.
3. Замени текст в [квадратных скобках] на своё, лишнее удали.
4. Запусти `claude` в папке проекта — он прочитает файл сам.

Шаблон специально назван не `CLAUDE.md`: иначе Claude Code, запущенный в этой папке, принял бы его за настоящие правила.
