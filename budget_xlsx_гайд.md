# СУММА — бюджет поездки файлом Excel

Claude может выдать скачиваемый XLSX с формулами прямо из чата.
Числа ниже — учебный пример, а не цены билетов или прогноз расходов.

## Шаги
1. В Claude открой **Settings → Capabilities → Create and edit files**.
2. Старое название переключателя: **Code execution and file creation**.
3. Создай чат и вставь запрос ниже, заменив пример своими данными.
4. Скачай предложенный файл `.xlsx` и открой его в Excel или совместимом приложении.
5. Проверь формулы и единицы измерения; затем внеси один новый расход.

## Готовый запрос
«Создай XLSX: бюджет поездки. Все суммы в рублях. Лимит 10000; дорога туда 2000; обратно 2000; жильё 3000; еда 1000. Колонки: статья, сумма. Итог расходов и остаток считай формулами, не готовыми числами. Ничего не додумывай».
«Оставь строки для новых расходов; итог должен их учитывать. Отрицательный остаток выделяй».

## Проверка на примере
Исходный итог: 8000, остаток: 2000.
Измени еду на 1500: итог должен стать 8500, остаток — 1500.
Добавь расход 500 в предусмотренную строку: итог 9000, остаток 1000.
Если результат не изменился, попроси Claude исправить формулы в новой копии файла.
Для разных валют сначала согласуй курс и дату; не складывай их как одинаковые единицы.
В рабочем аккаунте возможность создания файлов может быть ограничена администратором.
