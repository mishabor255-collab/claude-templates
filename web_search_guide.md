# FIND — check your plans before leaving

Claude's web search retrieves current pages and supplies source links.
It cannot guarantee that a venue has updated its own schedule immediately.

## In Claude
1. Start a new chat on the web or Desktop.
2. If the **+** menu contains **Web search**, turn it on.
3. The new interface has no toggle: explicitly ask Claude to search the web.
4. Give the exact venue, city, and calendar date of your visit.
5. Send the prompt below and wait for the search results.
6. Open the venue's own website and check dates, hours, and exceptions.

## Copy this prompt
“Search the web for [venue, city] opening hours on [date]. Check the venue's website and closure notices. Link sources. Flag conflicting information or missing dates.”
“Find one nearby backup for that same date. Do not book anything.”

## Your checks
Verify the address: similarly named places may have multiple branches.
Check holidays, closed days, and notice dates rather than trusting a search snippet.
If opening hours determine your trip, resolve conflicting information with the venue.
Search uses Claude's allowance; workplace administrators may restrict it.
