# SIMPLE — the Karpathy guidelines skill in the Claude app

The skill from the andrej-karpathy-skills repo is a set of rules for coding tasks:
clarify the task, keep it simple, change only what's needed, verify the result.
It guides the model; it's not a guarantee — still review the changes.

## Steps (Claude app or website)
1. Open https://github.com/multica-ai/andrej-karpathy-skills → **Code → Download ZIP**, unzip it.
2. Find the `skills/karpathy-guidelines` folder (it contains `SKILL.md`).
3. Zip **that folder** (Mac: right-click → Compress; Windows: Send to → Compressed folder).
4. In Claude: **Settings → Capabilities** — turn on code execution if it's off.
5. In the **Skills** section, click **Upload skill** and pick your ZIP.
6. Toggle the skill on. Try: "Make one Order button, nothing extra."

## No Skills section?
- Skills aren't available on every plan — check Claude's help center.
- Fallback: create a Project and paste the repo's `CLAUDE.md` text into the project instructions.
