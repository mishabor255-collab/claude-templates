# MEMORY: correct outdated information in Claude

This changes saved memory rather than reopening an old conversation.
Settings labels vary between interface versions.

1. Open Claude on the web or desktop.
2. Go to Settings → Your Claude → Your memory → Manage.
3. Older layouts use Settings → Memory; the legacy experience uses Capabilities → View and manage memory.
4. Find the outdated entry about your work or project.
5. Open its topic and edit icon; a summary-based interface provides a memory editing field instead.
6. Example correction:
> The flower shop has closed. My current work project is a football podcast. Do not suggest shop ideas unless I ask for them.
7. Save the edit and read the entry again.
8. Start a new chat: “Suggest topics for my current work project.”
9. Check the answer reflects the update; clarify the entry if necessary.

You can also ask Claude to update memory directly in a chat.
Do not select Reset memory to correct one item; it affects all memory.
If memory controls are missing, check feature access and organization restrictions.
