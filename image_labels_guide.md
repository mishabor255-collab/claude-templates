# PHOTO: explain a clothing care label

Use Claude on the web or in the desktop app.
The goal is to interpret visible symbols without guessing unclear details.

1. Photograph the label in good light without glare.
2. Make sure every symbol is visible; take a close-up if needed.
3. Start a new Claude chat and click “+” beside the input.
4. Select Add files or photos and attach your picture.
5. Send this prompt:
> Explain each visible care symbol. Describe its shape first, then its meaning. Flag unclear details instead of guessing. Do not infer the fabric composition without a readable label.
6. If a symbol is unclear, upload a sharper close-up.
7. Compare the explanation with the garment manufacturer's care instructions.
8. Save a clear checklist; do not change the wash cycle based on a model's guess.

Supported formats include JPEG, PNG, GIF and WebP.
Image interpretation can be wrong, especially with tiny symbols.
