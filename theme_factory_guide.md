# COLOR — consistent styling with theme-factory

This skill from anthropics/skills provides coordinated colors and fonts.
The video's star count belongs to the whole repository, not this individual skill.

## Prepare without a terminal
1. Open the [repository](https://github.com/anthropics/skills) and choose **Code → Download ZIP**.
2. Extract it in Finder or File Explorer and find `skills/theme-factory`.
3. Read `SKILL.md`; keep all bundled files, including `themes` and `theme-showcase.pdf`.
4. Use Finder's Compress or File Explorer's ZIP command to archive the `theme-factory` folder.
5. Upload only that skill folder's ZIP, not the entire repository archive.

## In Claude
6. Check **Settings → Capabilities → Create and edit files**, formerly **Code execution and file creation**.
7. Open **Customize → Skills → + → + Create skill → Upload a skill**.
8. Upload the ZIP and enable the skill. Workplace administrators may restrict uploads.
9. Start a chat, attach your deck, and use the prompt below.

## Copy this prompt
“Use theme-factory. Show me the theme choices and wait for my selection. Then style a copy of this deck without changing its content.”
After reviewing: “Use Modern Minimalist on a copy. Keep the original.”
Open the result and check line breaks, readability, and missing slides.
This skill does not fact-check a deck or guarantee perfect layout.
