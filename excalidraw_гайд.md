# СВЯЗИ — диаграмма в чате Claude

Excalidraw MCP рисует схемы и позволяет редактировать их в совместимом чате.
Ниже используется удалённое подключение, без локальной установки.

## Шаги в приложении
1. В Claude открой **Customize → Connectors**.
2. Выбери **Add → Custom → Web**.
3. Назови подключение Excalidraw и вставь адрес из README: `https://mcp.excalidraw.com`.
4. Пройди **Continue**, проверь предложенные настройки входа и заверши **Add**.
5. В старом интерфейсе путь: **Settings → Connectors → Add custom connector**.
6. В новом чате разреши инструменты Excalidraw и отправь запрос ниже.
7. Открой схему, проверь подписи и попроси поправить расположение блоков.

## Готовый запрос
«Нарисуй в Excalidraw схему: Организатор → Гости; Организатор → Площадка; Площадка → Кейтеринг. Используй только эти связи. Неизвестные связи уточняй. Не добавляй логотипы».
Для семейного примера сначала замени имена вымышленными и перечисли только нужные связи.
Проверь направление каждой стрелки; удобный рисунок ещё не означает правильную схему.

## Если не получилось
В рабочем аккаунте добавление может быть доступно только администратору.
Для рисунка внутри чата клиент должен поддерживать MCP Apps; обнови приложение или попробуй веб-версию.
Используется внешний сервер, поэтому не отправляй ему ненужные личные сведения.
