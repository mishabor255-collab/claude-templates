# КРУГ — колесо дежурств в Claude

Артефакт — отдельный результат рядом с чатом, например небольшой интерактивный инструмент.
Открой Claude в браузере или Desktop.

## Шаги
1. Проверь **Settings → Capabilities → Create and edit files**.
2. В прежнем оформлении этот переключатель называется **Code execution and file creation**.
3. Создай новый чат и отправь запрос ниже.
4. Открой созданный артефакт рядом с перепиской.
5. Впиши только людей, которые действительно участвуют в дежурстве.
6. Нажми кнопку, затем попроси исправить обнаруженные ошибки прямо в чате.

## Готовый запрос
«Создай интерактивный артефакт: колесо дежурств. Поле для имён, кнопка “Крутить”, один выбранный участник. Все участники имеют равный шанс. Покажи результат крупно. Не добавляй регистрацию и внешние сервисы».
«Добавь проверку: без имён крутить нельзя, пустые строки не считаются участниками».

## Проверка
Попробуй пустой список, одного участника и несколько разных имён.
При одном участнике всегда должен выпадать он; при пустом списке — понятная подсказка.
Несколько вращений не доказывают равенство шансов: попроси объяснить способ выбора.
Сохранение результатов между открытиями здесь не обещается и не требуется.
В рабочем аккаунте доступ к созданию файлов может определять администратор.
